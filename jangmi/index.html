공시가격은 언제 발표되나요?

공동주택 공시가격은 매년 1월 1일 기준으로 산정되어 3월 중순 공시가격(안)이 공개되고(약 3주간 의견 청취), 4월 말 결정·공시됩니다. 이 사이트는 3월 15일·4월 29일 즈음 일정 알림을, 결정·공시 가격이 올라오면 가격 알림을 보냅니다.

어떻게 동작하나요?

GitHub Actions가 매일 오전 9시·오후 6시(한국 시간)에 부동산공시가격알리미를 조회해 이 페이지의 데이터를 갱신하고, 새 공시가 있으면 알림을 보냅니다. 실행 기록 보기

세대 등록·해지는 누가 할 수 있나요?

저장소 소유자(와 협업자)의 요청만 처리됩니다. 다른 사람이 요청하면 자동으로 거절됩니다.

토픽을 다른 사람이 알면요?

ntfy 토픽은 이름을 아는 사람 누구나 구독할 수 있습니다. 공시가격은 공개 정보라 문제는 크지 않지만, 가족만 받고 싶다면 토픽 이름을 공유하지 마세요.

출처: 부동산공시가격알리미(realtyprice.kr). 공시가격은 세금 산정 기준이 되는 정부 공시가격이며 시세·실거래가가 아닙니다. 이 사이트는 정부 기관과 무관합니다.
