# 꼬마전구 직렬·병렬 실험실 (물길 비유)

꼬마전구를 직렬·병렬로 연결했을 때 밝기가 왜 달라지는지, 물길(펌프·높이·수문·물레방아)에 빗대어 직접 조작하며 이해하는 시뮬레이션입니다.

**바로 쓰기:** https://deepsky-sh.github.io/bulb-water-analogy/

| 물길 | 전기 |
|---|---|
| 펌프 | 건전지 |
| 물이 올라간 높이 | 전압 |
| 흐르는 물의 양 | 전류 |
| 좁은 수문 | 저항 |
| 물레방아의 힘 | 전구 밝기 |

설치할 것은 없고 `index.html` 하나로 동작합니다.
